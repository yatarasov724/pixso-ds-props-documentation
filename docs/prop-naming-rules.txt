ПРАВИЛА НЕЙМИНГА ПРОПОВ ДИЗАЙН-СИСТЕМЫ
========================================


СИНТАКСИС
----------

kebab-case для всех имён (строчные буквы, слова через дефис)
  Правильно:   icon-before
  Неправильно: iconBefore, icon_before, IconBefore

Без префикса is у булевых
  Правильно:   disabled, loading
  Неправильно: isDisabled, isLoading

Без префикса has
  Правильно:   closable, scrollbar
  Неправильно: hasCloseButton, hasScrollbar

Без префикса show
  Правильно:   actions, image
  Неправильно: showActions, showImage

Слот: content / element / icon + позиция суффиксом
  Правильно:   content-before, icon-after
  Неправильно: leftContent, prefixIcon, startIcon


========================================
СТАНДАРТНЫЕ ПРОПЫ: ОБЛИК И ПОВЕДЕНИЕ
========================================

ПРОП                ЧТО ОПИСЫВАЕТ                                    ЗАПРЕЩЁННЫЕ СИНОНИМЫ
variant             Функциональный тип + визуальная семантика         type, kind, appearance, color, intent
mode                Визуальный стиль (менее семантичен, чем variant)  theme, look, displayMode, colorMode
size                Высота, шрифт, внутренние отступы                 scale, dimension, small, large, inputSize
padding             Плотность без смены габаритов                     spacing, density, gap, indent
orientation         Направление главной оси                           direction, axis, layout, flow
state               Визуальный статус: enabled, hover, active, focus, disabled, readonly   status, uiState, interactionState
validation-status   Результат валидации (error / warning / success)   error, validity, hasError, fieldState

========================================
КЛЮЧЕВЫЕ РЕШЕНИЯ
========================================

variant vs mode
  variant — если проп меняет семантику ("зачем")
  mode    — если только внешний вид ("как")

state включает disabled / readonly и визуальные hover / active / focus
  loading — отдельный булевый проп

Позиция через суффикс, не через префикс
  Правильно:   icon-before, icon-after, content-left, element-top
  Неправильно: leftIcon, topElement, startContent

Слот: видимость и контент — один проп
  В дизайне: icon-before (boolean) + 🔄 icon-before (instance swap)
  В коде: оба маппятся на один проп icon-before
